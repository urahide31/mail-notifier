Mail Notifier

開発者本人が個人的に使用するメール通知ツールです。一般向けのサービスではありません。

Gmail API の gmail.send 権限のみを使用し、開発者本人のメールアドレス宛てにのみ通知を送信します。

This is a personal email notification tool used only by its developer. It uses the Gmail API gmail.send scope solely to send notifications to the developer's own address.
